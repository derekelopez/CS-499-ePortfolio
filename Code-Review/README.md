

\# CS-499 Capstone Code Review



\## Overview



This code review was prepared for CS-499: Computer Science Capstone at Southern New Hampshire University.



The review examines two previously developed computer science artifacts:



1\. Raspberry Pi Smart Thermostat (CS-350)

2\. Pirate Intelligent Agent (CS-370)



The purpose of the review was to evaluate the original implementations, identify opportunities for improvement, and establish a plan for enhancing software design, algorithms, data structures, and database integration.
