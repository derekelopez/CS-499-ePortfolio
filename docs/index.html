Enhancement One

Software Design and Engineering

Smart Thermostat | Raspberry Pi and Python

I enhanced my original Raspberry Pi thermostat by reorganizing its functionality into separate modules for configuration, thermostat control, hardware interaction, telemetry communication, and the main application. This makes the application easier to understand, maintain, extend, and troubleshoot than a single tightly coupled implementation.

Implemented Enhancements

  • Preserved the OFF → HEAT → COOL operating-state cycle and button-based setpoint adjustments.
  • Separated thermostat decision-making from Raspberry Pi hardware access using thermostat_core.py, hardware_pi.py, and main.py.
  • Added telemetry_client.py to transmit device readings to the backend used in Enhancement Three.
  • Verified operation on physical Raspberry Pi hardware, including state changes, setpoint controls, LCD output, and successful telemetry transmission.

Skills demonstrated: modular software architecture, interface separation, configuration management, hardware/software integration, debugging, and system verification.

Enhancement Two

Algorithms and Data Structures

Pirate Intelligent Agent | A* Search and Deep Q-Learning

I improved the original treasure-hunt intelligent agent by correcting environment and reward-handling behavior, validating maze inputs, and implementing A* pathfinding as a deterministic comparison to the existing deep Q-learning (DQN) approach. I then evaluated both methods using the same 8 x 8 maze and 50 valid starting positions.

Implemented Enhancements

  • Added an A* search implementation that uses a Manhattan-distance heuristic, a priority queue (heapq), and cost and parent tracking.
  • Improved maze-state validation and handling of invalid or previously visited moves.
  • Collected comparable outcome measures, including completion rates and path lengths.
  • Saved the evaluated DQN model as dqn_pirate_agent_1000.keras.
50 / 50 A* starts solved (100%)
15.64 A* average path length, moves
1 / 50 DQN starts solved (2%)
8 x 8 Evaluation maze

Results: A* solved all 50 tested starts without a training phase. The DQN model, trained for 1000 epochs in this experiment, succeeded on only one start. The successful DQN path took one move; because it was the sole success, that path length is not directly comparable to the A* average. These results show that A* was more reliable under the tested conditions, not that A* universally outperforms reinforcement learning.

Enhancement Three

Databases

Smart Thermostat IoT Telemetry | Flask REST API and MongoDB

I extended the enhanced thermostat into a working IoT telemetry system. The Raspberry Pi sends timestamped temperature, humidity, setpoint, and operating-state readings to a Python Flask API. The server validates incoming records and persists them in MongoDB, making historical data available for querying and summary statistics.

Implemented Enhancements

  • Created a Flask backend with a /api/health endpoint and a POST /api/readings ingestion endpoint.
  • Added input checks for required fields, accepted thermostat states, numeric measurements, and timestamp formatting.
  • Implemented MongoDB connectivity and insertion of validated telemetry documents.
  • Integrated live readings from the Raspberry Pi and confirmed the resulting records in MongoDB.
  • Implemented a statistics query endpoint, GET /api/readings/statistics, with optional time-range filtering and metrics for temperature, humidity, state counts, and state durations.
  • Verified endpoint behavior through HTTP requests and inspected stored records using MongoDB Compass.

Example verified output: A six-reading query returned an average temperature of 82.91°F, average humidity of 40.94%, and operating-state counts for the selected interval.

Security and deployment note: Input validation is implemented, but this project should not be presented as production-secure. Authentication, encrypted transport, access controls, and production deployment hardening remain possible future improvements.
